Data contract

All visible homepage and shared-CTA content now comes from the Atlas API at runtime: text, numbers, image URLs, links, phone values, CTA labels, query-state labels, and contact-form status copy. constants/copy.ts remains only as a seed/type source and is not used as a rendering fallback.

  • Hero media uses the required API image URL; it is not replaced with a bundled path.
  • Payment, medical note, ISMS, apply labels, and CTA labels render the API field directly.
  • Required CTA fields are required by the CMS mapper; missing data is exposed as a visible [missing: ...] marker instead of silently borrowing hardcoded copy.
  • The sticky CTA renders the API sticky_request_label directly, including the client-requested お問合せ label.
  • Loading, error, retry, empty, and contact-form status labels are required Atlas fields; missing values surface a visible marker rather than a bundled fallback.
